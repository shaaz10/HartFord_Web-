# C# Parking Lot Assignment

This folder contains the step-by-step implementation of the Week 6 Parking Lot assignment, as well as the final complete solution.

## Directory Structure

- **Requirement1**: Implements `Vehicle` and `Ticket` classes with `Equals` comparison logic.
- **Requirement2**: Adds `ParkingLot` class with CRUD operations (Add, Remove, Display).
- **Requirement3**: Adds `ValidateRegistrationNo` logic for Vehicle registration numbers.
- **Requirement4**: Implements `VehicleBO` for searching vehicles by Type or Parked Time.
- **Requirement5**: Implements sorting (by Weight using `IComparable` and by Parked Time using `IComparer`).
- **Requirement6**: Implements `TypeWiseCount` to count vehicles by type.
- **ParkingLotFinal**: The **complete, integrated solution** containing all the above features in a single application with a unified menu.

## How to Run

To run any specific requirement or the final solution, navigate to the folder and run:
```bash
dotnet run
```
For example, to run the final solution:
```bash
cd ParkingLotFinal
dotnet run
```

# Exercise 4 - Electricity Bill Calculator

## Description
A console application to generate electricity bills with proper formatting using characters. The application calculates charges based on consumption slabs and adds meter rent based on connection type.

## Features
- Professional bill formatting with box drawing characters
- Tiered pricing structure
- Fixed meter rent based on connection type
- Comprehensive customer information

## Pricing Structure

### Electricity Charges (per unit consumed)
| Units | Rate |
|-------|------|
| First 100 units | ?1.5 / unit |
| Next 150 units (101-250) | ?2.5 / unit |
| Next 300 units (251-550) | ?4.5 / unit |
| Above 1000 units | ?7.5 / unit |

### Meter Rent (Fixed Amount)
| Connection Type | Amount |
|---|---|
| Industrial | ?2,500 |
| Business | ?1,500 |
| Domestic | ?1,000 |
| Agricultural | Free |

## How to Run
1. Compile: `dotnet run`
2. Enter customer details:
   - Customer ID
   - Customer Name
   - Address
   - Phone Number
   - Email ID
3. Select connection type (1-4)
4. Enter meter readings:
   - Previous Reading
   - Current Reading
5. The application will display the formatted bill

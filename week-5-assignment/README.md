# Week 5 Assignment - C# Console Applications

This project contains four console applications demonstrating various C# programming concepts including mathematical patterns, geometric calculations, object-oriented programming, and formatted output.

## Projects Included

### Exercise 1: Cricket Statistics Pattern Prediction
- **Description**: Predicts cricket match runs based on a mathematical series pattern
- **Concepts**: Mathematical formulas, loop patterns, input validation
- **Location**: `Exercise1-CricketStats/`

### Exercise 2: Circle Intersection Game
- **Description**: Determines geometric relationship between two circles
- **Concepts**: Geometric calculations, distance formula, conditional logic
- **Location**: `Exercise2-CircleIntersection/`

### Exercise 3: Employee Salary Calculator
- **Description**: Calculates net salary with allowances and deductions
- **Concepts**: Object-oriented programming, static methods, exception handling
- **Location**: `Exercise3-SalaryCalculator/`
  - Includes a reusable `SalaryCalculator` library
  - Console application demonstrating library usage

### Exercise 4: Electricity Bill Calculator
- **Description**: Generates formatted electricity bills with tiered pricing
- **Concepts**: String formatting, switch statements, user input validation, formatted output
- **Location**: `Exercise4-ElectricityBill/`

## Requirements
- .NET 6.0 or higher
- Visual Studio or VS Code with C# extensions
- PowerShell or Command Prompt for terminal commands

## How to Run Each Exercise

Each exercise can be run independently. Navigate to the exercise directory and run:

```bash
cd Exercise1-CricketStats
dotnet run

cd ../Exercise2-CircleIntersection
dotnet run

cd ../Exercise3-SalaryCalculator
dotnet run

cd ../Exercise4-ElectricityBill
dotnet run
```
